# data/

Scripts or spreadsheets that produce the figures in `../evidence.json`.

A figure shown on a slide is computed here, not typed into the slide. Each one carries a tier:

| Tier | Meaning | Needs |
|---|---|---|
| V | Verified: published by a primary source | a ref |
| P | Project: measured or computed by you | a method or a ref |
| S | Assumption: an estimate | the slide must say so |
| D | Decision: a target the team chose | the slide must say so |
