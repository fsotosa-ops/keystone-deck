# Type: class or workshop

## Order per concept
Intuition (a picture or analogy) → a worked example with real numbers → the formal version → a check question → common traps.

## Scenes
`html` for intuition diagrams, `figures` or `projection` for the worked example, `cards` for traps, `appendix-thread` for exercises.

## Rules
- Define every symbol before using it.
- The check question has one right answer and explains the wrong ones in the notes.
- Never introduce data or methods outside the course material.
